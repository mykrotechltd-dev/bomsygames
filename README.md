# Bomsy Games

Homepage concept for **Bomsy Games**, the Nigerian sports brand behind **Bomsy Wall Tennis** — a homegrown racquet sport played against a numbered target board, already contested in schools and universities across Rivers State.

## Contents

- `index.html` — single-file static homepage (hero, tournaments, gallery, news, footer). No build step; open directly in a browser or deploy as-is (e.g. GitHub Pages).

## Content sources

Copy is grounded in the Bomsy Wall Tennis Report (Issue #001, April 2025): the brand's stated vision ("bringing racket sport to your doorstep"), mission, and its three real tournaments — the Dietans International Schools BWT Tournament (Season 1), the Rivers State University Postgraduate Sports Festival, and the 2025 Valentine Cup (Season 2) — plus the upcoming Rivers Secondary Schools Championship.
